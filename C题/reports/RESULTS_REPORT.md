# 计算结果报告

> 本报告记录代码阶段的求解口径、全年结果、代表日数值、费用构成与一致性校验。所有论文数值以本报告与 `results/` 内文件为准。

## 1. 运行环境与求解器

- Python 3.12（Anaconda）、numpy 2.5、pandas 2.3、openpyxl 3.1、scipy 1.16（HiGHS 求解线性规划）。
- 模型为**线性规划（LP）**，不使用二进制变量：储能同一时段充放电各承担 `±p` 且无可售电收益、每次启停损耗 `0.9η`，故最优解天然满足充放互斥，无需 0-1 变量（避免 HiGHS 数值性不可行与求解时间膨胀）。
- 求解参数：HiGHS 内点/单纯形默认容差；逐年逐日独立求解，共 334 个结果日 × 4 个子问题，全部返回最优可行解。
- 附件2 光伏/负荷工作表按"夜间均值≈0 者为光伏"自动识别（全年 365 日、144 点）。附件3 日期逐日首行填充并转 datetime；整点预测按"发布时刻+h 对应绝对小时"线性插值到 144 个十分钟网格。

## 2. 能量与费用口径

| 项 | 口径 |
|---|---|
| 时段 | 144 个 10 分钟时段，`Δt=1/6 h`；单位全部 kWh |
| 储能 | 容量 12000 kWh，运行区间 1200–10800 kWh，初态/末态 6000 kWh；充放电效率 90%（电荷 SOC 递推 `e_t=e_{t-1}+0.9C_t-D_t/0.9`） |
| 功率限 | 最大充放电功率 5000 kW → 单时段最大能量 833.333 kWh |
| 功率平衡 | `购电 + PV·Δt + 放电 = 负荷·Δt + 充电 + 弃光`，弃光 `curt≥0` 吸收光伏过剩；购电 `q≥0`（不外售） |
| 问题2 | 计划购电量按 0:00 预报确定；实际执行按实际光伏再调度储能，缺口由**紧急购电（5×交易价）**补齐 |
| 问题3 | 0:00 定日前计划；6:00/12:00/18:00 依最新预报重优化**调整购电量**；调整量高于计划量部分按 **1.5×**、低于部分按 **0.5×** 结算，加上紧急购电 5× |
| 问题4 | 用附件4 动态电价替换固定电价，重算问题2（result4-2）与问题3（result4-3） |

**问题1（附件1 单日）**：全天计划购电量 86,108 kWh，购电费 55,363 元；储能充电 17,837 kWh、放电 14,448 kWh；弃光 0 kWh；0:00 与 24:00 储电均为 6000 kWh。

**要点解读（问题3 是否需要其他时刻预报）**：
- 引入 6:00/12:00/18:00 三次预报并允许调整购电后，紧急购电量从约 30,102 kWh 骤降至 808 kWh（降约 97%），说明"其他时刻预报"能显著消除预测误差导致的供电缺口。
- 但调整过程产生约 90.5 万元的一次性偏差结算费用（上调 1.5× 与下调 0.5×），超过其节省的紧急购电费约 14.7 万元，故**总费用上升**。因此从"减少紧急购电（供电可靠性/风险）"看，引入后续预报是必要的；从"单纯总购电费用最小"看，基线 0:00 预报方案更省。论文据此给出"是否引入"应结合可靠性指标与偏差结算成本加权判断。

## 5. 一致性校验

代码在求解后对每个解执行：功率平衡残差、SOC 递推残差、SOC 上下界违规、充放互斥（同时非零时段数）、24:00 储能=6000 及费用逐项重算。全部通过；代表日校验示例：
- 2025-06-21：计划可行，SOC ∈ [1200,10800]，e_end=6000，执行紧急费 0（预报=实际时无缺口）。
- 2025-12-21：执行紧急量 5.7 kWh（冬日光伏预报偏差导致的微小缺口）。
- 费用恒等式 `cost = Σ p·q` 在各日成立至 1e-6 级。
